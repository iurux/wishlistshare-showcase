# WishListShare

**Try it:** https://iurux-wishlistshare.ruixu411.workers.dev

Share a wishlist with friends, let them claim gifts without spoiling the surprise, and track a savings fund toward the things you want.

<!-- screenshots/wishlist.png, screenshots/fund.png -->

## Features

- **Paste a link, get an item** — name, price and image are pulled from the product page automatically
- **Prioritize by dragging** — the Wish Fund shows how far your savings go down the list
- **Real prices** — converted to your currency, with estimated sales tax
- **Secret claiming** — friends open your share link and claim gifts without you seeing who
- **Guest mode** — try it without signing up

## Built with

TanStack Start (React 19, Vite) · Tailwind CSS · Supabase (Postgres, Auth, Realtime, row-level security) · Cloudflare Workers
